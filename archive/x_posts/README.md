# Buffett has essentially no investment-relevant X feed

**Cutoff: 2026-10-25.** No usable, authenticated Buffett investment-decision X-post series was established in this research. Do not invent posts, status IDs or precise timestamps to imitate Ackman. Berkshire’s shareholder letters and meeting/interview statements are the appropriate evidence. This does not claim that an account using his name never existed or never posted.

- public_statements.md: human-readable, dated, sourced verbatim excerpts explaining specific decisions.
- public_statements.json: same top-level fields as Ackman’s archive (archive, cutoff_date, retrieved_date, method, text_format, limitations, requested_topics, posts); each record uses date, url, topic_tags, states_buy_sell_reason, reason_timing, source_container_url and full_text. url points to the primary source, not X.
- topic_tags identify speaker and decider, including unknown where needed. Abel’s 2026 words are not Buffett’s.

The corpus includes Sanborn/Dempster in 1961/1963, 1969 liquidation and letters through Abel’s 2026-02-28 letter. Multiple excerpts can concern one transaction. full_text is explicitly an excerpt, not the complete letter or speech. Month-only dates represent unresolved exact release dates. No X API was used.

Primary anchors: [Berkshire letters index](https://www.berkshirehathaway.com/letters/letters.html), [Buffett’s 2025-11-10 statement](https://www.berkshirehathaway.com/news/nov1025.pdf), [Abel’s 2026-02-28 letter](https://www.berkshirehathaway.com/letters/2025ltr.pdf). See each record for its dated source.
