Calculate gross spread as $95 minus the current price, divided by current price; annualize only using an explicit closing-time assumption. Expected value must subtract failure probability times the decline to stand-alone value and account for delay. A large headline discount is not free money. [Source above.]

Technical context: merger arbitrage is a contingent cash-flow problem. Separate the promised consideration, financing, approvals, termination rights, outside date and possible remedies. Gross spread is not expected return: completion probability, time and the break-price loss all matter. A bidder's ability to pay does not settle regulatory approval. Stand-alone valuation is important even if the intended holding period ends at closing, because the target remains a public business if the transaction fails. Do not treat an original pre-announcement stock purchase and a post-announcement workout as the same investment thesis merely because they use the same ticker. [Source above; analytical framework.]

Valuation discipline: use a consistent claim and denominator. Enterprise value should be compared with cash generation before financing; common value should be compared with cash available after senior claims. Explicitly distinguish sustainable earnings from annualizing one quarter. A current quote from a different date, an eventual transaction price and an investor's later disclosed average cost are not substitutes for the cutoff price. State a range of operating assumptions, compare the result with liquid alternatives and require a margin of safety that survives a less favorable case. When a current input is unavailable, leave the numerical valuation incomplete instead of embedding an untraceable estimate.
